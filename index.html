Sauvegarder mes données

Les données restent sur cet appareil et dans ce navigateur. Elles ne sont pas synchronisées entre appareils. Sauvegarde régulièrement ton fichier, surtout avant de changer de téléphone ou d'effacer les données du navigateur.

La sauvegarde chiffrée nécessite ton mot de passe pour être restaurée. Conserve-la dans un endroit sûr.

La restauration remplace les données actuelles après confirmation. Sauvegarde le fichier chiffré ailleurs que sur ce seul téléphone (par exemple sur un support personnel protégé). Le mot de passe est indispensable.

🔐 Suivi-Clients privé

Crée un mot de passe personnel (12 caractères minimum). Il protège les données sur ce téléphone. Ne le communique à personne : sans lui, tes données ne pourront pas être récupérées.

Garde ta sauvegarde JSON précédente jusqu'à ce que tu aies vérifié la nouvelle sauvegarde chiffrée.

Suivi indicatif · Ne remplace pas une fiche de paie ou déclaration CESU.
